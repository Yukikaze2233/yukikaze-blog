# 博客搭建手记：从静态主页到真正的博客

这篇文章既是本站的搭建记录，也是一个测试页面：代码高亮、数学公式、引用、表格都会在这里演示。

## 架构

仍然是纯静态站点，没有后端数据库。文章是 `posts/` 目录下的 Markdown 文件，浏览器加载后用 Markdown-it 渲染。

```cpp
// 技术博客的第一段代码，必须从 C++ 开始
#include <print>

int main() {
    std::println("Hello, blog!");
    return 0;
}
```

## 一个公式

在 RoboMaster 里，云台射击常要处理预测问题。比如最简单的匀速直线运动模型：

$$
\mathbf{x}_{k+1} = \mathbf{F} \mathbf{x}_k + \mathbf{w}_k
$$

行内公式也可以写：$e^{i\pi} + 1 = 0$。

## 关于写作流程

> 写作会逼我把「我以为我懂了」变成「我能讲清楚」。

以后每篇文章只需要：

1. 在 `posts/` 下新建一个 Markdown 文件。
2. 顶部写好标题、日期、摘要和标签。
3. 提交到仓库，首页会自动出现这篇文章。
