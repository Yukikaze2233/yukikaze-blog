# Yukikaze Blog

基于原生 HTML + CSS + JavaScript 构建的个人博客静态站。视觉与交互风格延续自个人主页（Yukikaze2233/homepage）。

## 本地预览

```bash
cd /home/yukikaze/Documents/workspace/yukikaze-blog
python3 -m http.server 8000
```

浏览器打开 <http://127.0.0.1:8000/>。

## 部署

纯静态站点，可直接部署到 GitHub Pages / Cloudflare Pages。

- 构建命令：无
- 输出目录：`/`

## 结构

```text
index.html
static/
  css/style.css
  js/script.js
  img/logo.png
  img/background.jpg
  img/favicon.ico
```
